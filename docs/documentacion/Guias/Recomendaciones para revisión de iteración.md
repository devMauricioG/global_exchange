**Ingeniería de Software II \- IIN \- 2026**  
**Recomendaciones para revisión de sprint**  
\- Todos los miembros del equipo DEBEN estar presentes  
\- El equipo a evaluar DEBE estar 10 minutos antes de la revisión, en el medio establecido para el efecto.  
\- La revisión se realiza en una sola computadora  
\- El profesor dirige la revisión del sprint  
\- Durante la revisión no se pueden hacer cambios al código ni a la configuración del software, salvo expresa solicitud del profesor.  
\- Todos los miembros del equipo DEBEN manejar TODAS las herramientas utilizadas en el proyecto  
\- Todos los miembros del equipo DEBEN conocer técnicamente TODO el software del proyecto.  
\- Todo el software DEBE estar en el repositorio de control de versiones (Git, etc) y en la revisión se debe hacer checkout con el TAG respectivo a la revisión.  
\- La integración de software utilizando un repositorio de control de versiones es un trabajo difícil y requiere mucho orden y disciplina. La calidad de su trabajo depende de esto. Inviertan tiempo en esto.  
\- Las pruebas unitarias DEBEN registrarse por fecha y artefacto probado, de manera a ir mostrando a medida que avanzan los sprints las pruebas unitarias nuevas que el equipo va haciendo.  
\- La documentación de código fuente DEBEN registrarse por fecha y artefacto documentado de manera a ir mostrando a medida que avanzan las nuevas documentaciones que el equipo va haciendo.  
\- La interfaz de usuario DEBE ser funcionalmente coherente y con estilo estándar para todo el proyecto.   
\- El IDE debe estar integrado al control de versiones y deben saber utilizarlo TODOS los miembros del equipo  
\- Al momento de la presentación tener disponible TODOS los comandos para realizar las documentaciones, pruebas, despliegues, si es posible en un script. Para no perder tiempo.  
\- El Tag del sprint debe ser antes de la hora de inicio de las evaluaciones.  
\- El usuario **admin** de Django **NO** se debe utilizar para el sistema.  
\- La fecha y hora de las planificaciones deben ser de antes de la fecha de entrega.
